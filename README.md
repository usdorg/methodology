# US Directory Methodology

How [US Directory](https://usd.org/) measures local service businesses: what we check, where each fact comes from, why it matters to a customer, and how a business can improve.

The method is published here before the first ranking, so anyone can read it, question it and propose changes. The rendered version lives at [usd.org/methodology](https://usd.org/methodology/).

## Status

Version 0.1 (October 2026). This release contains the principles and the list of factors. Weights, formulas and the machine-readable factor file come with version 3.0, before any score is shown on the site. See [CHANGELOG.md](CHANGELOG.md).

## Scope

The first coverage is plumbing in Florida, starting with St. Petersburg. Sources are named for Florida; other states will add their own public records under the same factors.

## Corrections to a business listing

This repository is about the method. If a fact about a specific business is wrong, use the correction link on that business page at usd.org. Corrections are free and are judged by the same rules for every business.
